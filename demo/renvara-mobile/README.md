## Running it

Open the HTML file in a browser. It needs no server and no build: the whole
app is inline. The only external request is the Plus Jakarta Sans font from
Google Fonts, and the page uses a system font when it is offline.

- On a wide screen with a mouse, the app is shown in a phone frame next to a
  short guide. On a phone or narrow window, it fills the screen.
- Any username and password log in.
- Demo data is stored in this browser's `localStorage`, under the keys
  `renvara.demo.*` and `renvara.dashboard.period`, and resets to the sample
  data each day. Use "Vrati demo na početak" to reset it right away.

## Backtesting

Do not edit this file. To compare with a newer build, save that build next to
this one under a new dated name. Check that this copy is still unchanged
with:

```sh
sha256sum renvara-mobile-demo-2026-10-09.html
```
